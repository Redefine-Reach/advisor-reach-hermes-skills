Hermes Skills — Terms

Hermes Skills
The public, portable SKILL.md-format skills a customer's Hermes agent loads to operate AdvisorReach software — this repo, advisor-reach-hermes-skills (browser-use, circle-member-token, computer-use, connect-app, connect-mcp, daily-brief, email-outreach, ffmpeg-skill, gbp-scorecard, ghl, listing-presentation, mab-design-iteration, present-file, publish-site, retirement-calculator, schedule-text, video). Grounded in this repo's README.md ("Public, portable skills in the open SKILL.md format — usable by Hermes, Claude Code, Codex, Cursor, and any SKILL.md-compatible agent").
Circle Member Token
The one-hour Circle Member API access_token that a box mints for one of its own declared Circle members (POST {ADVISORREACH_API_URL}/circle/v1/auth-token with the member's email) and then presents as Authorization: Bearer to https://app.circle.so/api/headless/v1/... to read, find, and comment as that person. Minted on demand by the circle-member-token skill, never stored. Grounded in skills/circle-member-token/SKILL.md ("Getting a token", "Finding a post", "Commenting on a post").
Brief Job
A Scheduled Text whose content is the morning brief: created through the schedule-text skill with skills: ["schedule-text", "daily-brief"] and the daily-brief prompt template (first line User timezone: <IANA>, the DELIVERY FORMAT paragraph). When it fires it gathers only from connected sources, publishes a branded HTML page through present-file and texts a plain message under 550 characters ending Full brief: <link>. Grounded in skills/daily-brief/SKILL.md (sections 1–2).
Scheduled Text
A Hermes cron job on a customer box created by the schedule-text skill: a clock-time schedule written as a UTC cron expression (the box's scheduler runs in UTC with no configured timezone; the user's local time is converted with skills/schedule-text/references/timezones.md), or a delay one-shot passed as the tool's own in Nm; failure_deliver: local; the fire-time skills it must load; a self-contained prompt; and a Delivery Target verified with list to be the user's conversation. Grounded in skills/schedule-text/SKILL.md (sections A–D).
Delivery Target
The deliver value of a Hermes cron job — where its final response is posted. origin (the conversation the job was created from; captured automatically only in a gateway session such as SMS, never from hermes chat -q or the CLI) or telnyx_sms:+E164 reaches the customer; local saves the output to a file and texts nobody. The daily-brief skill verifies the Delivery Target with cronjob_manage action: list after every create. Grounded in Hermes tools/cronjob_tools.py (_origin_from_env; the deliver parameter description) and cron/jobs.py create_job ("origin" if origin else "local").
GHL Token File
The box's saved GoHighLevel OAuth token, /opt/data/ghl/token.json ($HERMES_HOME/ghl/token.json, the box volume), mode 0600, written atomically by skills/ghl/scripts/ghl.py from the AdvisorReach API's POST /crm/v1/claim and rewritten on every refresh; the script adds obtained_at/expires_at. Never printed, never read by the agent directly. A pending sign-in is /opt/data/ghl/pending.json (the OAuth state only).
