How this was scored

Feeder counties are ranked by the income of the households that moved from each county to {{ summary.destination }} (IRS Statistics of Income county-to-county migration, tax years 2022–2023). Pull (1–5) is that county's moved income relative to the top feeder. Affluence (1–5) is the average adjusted gross income per tax return in the ZIP (IRS SOI ZIP-code data, tax year 2022): $400K+ is 5, $250K+ 4, $175K+ 3, $125K+ 2, otherwise 1. Total = 0.55 × Pull + 0.45 × Affluence; Tier A is 4.0 or more, B is 3.0 to 3.99, C is below 3.0. ZIPs with fewer than 500 tax returns are left out. Each ZIP belongs to the county that holds most of its land (Census 2020 ZCTA-to-county file). A ZIP code matches a city in the agent database, so ZIPs from the same city return the same agents.
